## Agent guidance

Use the live public product page as the source of truth for current price, stock, availability, variants, promotions, delivery information, and purchase options.

Use dedicated public policy pages as the source of truth for policy questions.

Treat search results and other discovery pages as navigation aids rather than canonical product records.

Never expose or infer private customer, order, account, authentication, payment, administration, analytics, or security information.

Re-fetch live public pages before presenting time-sensitive facts.
