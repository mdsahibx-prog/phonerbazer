# PhonerBazar Catalogue Search

Read-only public catalogue discovery capability.

## Purpose

Find public PhonerBazar products by name, SKU, brand, or catalogue search.

## Canonical interface

https://www.phonerbazar.store/products

## Safety boundary

- Read-only discovery; no order creation or checkout submission.
- Product price, stock, variants, delivery, and promotion details must be read from the live public catalogue.
- No customer records, credentials, payment data, or private administration data are exposed.

## WebMCP

This document describes the public browser workflow advertised by the PhonerBazar ARD catalog. Agents should use the site's existing search/navigation controls and preserve normal user-visible confirmation for consequential actions.
